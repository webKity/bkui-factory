# Number 数字工具

`packages/ui-react/src/components/utils/number.ts` 使用原生 BigInt 系数与十进制指数提供十进制运算、比较、舍入和转换方法，无需第三方十进制计算库。运行环境需要支持 BigInt。以下说明以当前实现和返回类型为准。

## 快速开始

当前模块未从 `@bkreact/ui`、`@bkreact/ui/client` 或独立 npm 子路径导出。以下路径相对于 `packages/ui-react/src/components/utils/`，使用时需调整源码导入路径。

```ts
import { add, division, compareDecimal, roundDecimal } from './number';

add('0.1', '0.2'); // '0.3'，string
division('1', '3', { scale: 4, rounding: 'half-up' }); // '0.3333'
roundDecimal('1.255', 2, 'half-up'); // '1.26'
compareDecimal('9007199254740993', '9007199254740992'); // 1
```

`DecimalInput` 为 `string | number`。需要保留输入精度时优先传字符串；传入的 number 如果已发生精度损失，工具无法恢复。例如 `Number('9007199254740993')` 已经变成 `9007199254740992`。

## 运算与比较 API

| 方法 | 返回类型 | 行为 |
| --- | --- | --- |
| `add(left, right)` | `string` | 精确加法，普通十进制字符串 |
| `sub(left, right)` | `string` | 精确减法，普通十进制字符串 |
| `mul(left, right)` | `string` | 精确乘法，普通十进制字符串 |
| `division(left, right, options)` | `string` | 按 scale 和 rounding 舍入，固定小数位；除零抛出 RangeError |
| `compareDecimal(left, right)` | `-1`、`0` 或 `1` | 直接比较十进制输入，依次表示小于、等于、大于 |

`division` 必须传入 options 并明确指定 scale，rounding 默认 half-up。scale 必须是 0～1000 的整数，不会将 null、字符串等运行时输入隐式转换为数字。

```ts
division('1', '8', { scale: 3 }); // '0.125'
division('1', '8', { scale: 2 }); // '0.13'
division('1', '8', { scale: 2, rounding: 'down' }); // '0.12'
division('1', '0', { scale: 2 }); // 抛出 RangeError
```

除法会校验配置、舍入模式和两个操作数，除数为零时拒绝计算。调用方应捕获异常或在业务层处理无有效除数的情形。

### 精度、固定小数位与计算限制

算术和转换方法均返回字符串，不再经过 JavaScript number，字符串输入中的大整数和高精度小数不会因输出转换丢失精度。compareDecimal 仍返回数字 -1、0 或 1。

```ts
add('9007199254740993', '1'); // '9007199254740994'
mul('12345678901234567890', '2'); // '24691357802469135780'
division('1', '2', { scale: 4 }); // '0.5000'
roundDecimal('1.5', 2); // '1.50'
```

加、减、乘与普通转换去除无意义的小数末尾零。除法和舍入固定保留 scale 位，舍入为零时规范化负号，例如 roundDecimal('-0.001', 2) 返回 '0.00'。

每个输入尾数最多 10000 个数字（包含前导零和末尾零），显式指数绝对值最多 100000。加减运算对齐后的操作数、加减乘的实际结果系数，以及除法按 scale 缩放后的分子和分母，均不能超过 10000 位，超出时抛出 RangeError。实际结果在去除末尾零之前检查，因此进位产生第 10001 位也会被拒绝。乘法按实际乘积位数判断，两个操作数位数之和为 10001 时，乘积仍可能只有 10000 位。

```ts
mul('9'.repeat(10000), '1'); // 允许，实际乘积为 10000 位
mul('9'.repeat(10000), '9'); // RangeError：实际乘积为 10001 位
add('9'.repeat(10000), '1'); // RangeError：进位后为 10001 位
add('1e100000', '1e-100000'); // RangeError：对齐后超过工作精度限制
```

roundDecimal 补齐固定小数位后的系数也受 10000 位限制。工作精度不等于输出长度；普通字符串转换仍可能展开为较长文本。加减乘与普通转换还会检查非零结果最高有效位的十进制指数，范围为 -100000～100000。

运算使用 BigInt 整数计算，通过商和余数决定舍入；舍入模式由每次调用显式指定或使用默认值，不依赖外部库或全局精度配置。

## 舍入

| 方法 | 返回类型 | 行为 |
| --- | --- | --- |
| `roundDecimal(value, scale, rounding?)` | `string` | 按指定小数位和舍入模式处理，默认 half-up |
| `ceilDecimal(value, scale)` | `string` | 等同于 `roundDecimal(value, scale, 'ceil')`，向正无穷取整 |

两者的 scale 类型为 number，范围为 0～1000 的整数。`ceilDecimal('-1.231', 2)` 返回 `'-1.23'`；它不等同于远离零舍入。

| `DecimalRounding` | 规则 |
| --- | --- |
| `up` | 只要舍弃部分非零，就向远离零的方向舍入 |
| `down` | 向零截断 |
| `ceil` | 向正无穷方向舍入 |
| `floor` | 向负无穷方向舍入 |
| `half-up` | 舍入到最近值，中点向远离零的方向舍入 |
| `half-down` | 舍入到最近值，中点向零舍入 |
| `half-even` | 舍入到最近值，中点取保留位为偶数的结果 |
| `trunc` | 与 down 相同 |

## 转换与空值

| 方法 | 返回类型 | 当前行为 |
| --- | --- | --- |
| `scientificToPlainString(input)` | `string` | 将十进制输入展开为不含科学计数法的字符串 |
| `exponentialToString(input)` | `string` | 直接调用 scientificToPlainString |
| `toNonExponential(value)` | `string` | null、undefined、空白字符串返回空字符串；其他输入展开为普通十进制字符串 |

三个方法都从 BigInt 系数和十进制指数生成字符串，不经过 number 转换，因此字符串输入中的大数与高精度小数不会因输出转换丢失精度。输出会去除小数部分无意义的末尾零，负零输出为 `'0'`。number 输入进入函数前已丢失的精度仍无法恢复。

```ts
toNonExponential('1e-7'); // '0.0000001'
scientificToPlainString('1e21'); // '1000000000000000000000'
exponentialToString('9007199254740993'); // '9007199254740993'
toNonExponential('1.2300'); // '1.23'
```

## 输入与错误处理

字符串会先去除首尾空白，支持正负号、普通十进制与科学计数法，例如 `' +1.25 '`、`'.5'`、`'1.'`、`'1.e5'`、`'1e-3'`。不接受千分位分隔符、货币符号、十六进制字符串、NaN 或 Infinity。

| 错误 | 触发条件 |
| --- | --- |
| `TypeError` | 非法十进制输入、非有限 number、类型不是 string/number、不支持的舍入模式，或除法缺少 options |
| `RangeError` | scale 非法、除数为零，或输入尾数长度、显式指数、结果指数、运算工作精度超出上述限制 |

只有 `toNonExponential` 将 null、undefined 和空白字符串当作无值。其余方法遇到空白字符串会抛错；所有方法都同步执行，错误由调用方捕获。

```ts
try {
  add('1,000', '1');
} catch (error) {
  console.error(error); // TypeError
}
```

## 类型索引

| 类型 | 用途 |
| --- | --- |
| `DecimalInput` | `string | number` 输入 |
| `DecimalRounding` | 八种舍入模式 |
| `DivisionOptions` | `{ scale: number; rounding?: DecimalRounding }` |

兼容性：算术函数（含 ceilDecimal）由 number 改为 string；division 需要显式 options，除零改为抛错。接入方应按新类型处理返回值，不要在高精度链路中转回 number。
